# 🫀 Heart Disease Prediction using Machine Learning

## 📖 Description
This project predicts the likelihood of heart disease in patients using **Logistic Regression**, a supervised machine learning algorithm.  
It analyzes medical data such as **age, cholesterol, blood pressure, heart rate**, and other health metrics to determine the risk of heart disease.

## 🚀 Features
- Loads and analyzes a real-world heart disease dataset  
- Cleans and prepares the data for modeling  
- Trains a Logistic Regression model  
- Evaluates accuracy on both training and test datasets  
- Makes predictions on new patient data  

## 🧠 Technologies Used
- Python  
- NumPy  
- Pandas  
- Scikit-learn  
- Google Colab
